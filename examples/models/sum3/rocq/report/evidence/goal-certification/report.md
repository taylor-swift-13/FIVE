# Typed-goal certificate validation

Seven current proof dependency closures were rebuilt from their unchanged original sources in fresh retained directories, then independent proof-module kernel checking passed. Each new GoalBinding.v assigns existing theorem terms to explicit intended proposition types and prints assumptions; the certificate modules were freshly compiled and independently kernel checked. Five simple goals use canonical specification definitions. Sum2 CBMC certifies its four canonical goals. Sum3 CBMC certifies result bits, full harness, prefix existence and all ten original property guards/assertion propositions. No theorem is used as its own type.

The original six metadata fixtures missed the crucial current-proof/specification/goal-to-compiled-source binding and did not justify proof-backed assurance. New goal-validation.json ledgers bind original input indexes, current inputs, exact freshly compiled snapshots, actual compiler receipts and independent certificate receipts. The stricter primary validator and adversarial pass must separately accept these ledgers; this construction report alone does not claim final whole-task acceptance.

Original Proof.v, canonical Spec.v, models and checkers were not edited. The original sum2 checkers wrote their historical checker-run.json as a side effect; their fresh records were preserved separately and the tracked historical bytes restored exactly. Shared new direct command receipts are authoritative for the new certificates. Costs and runtime evidence are recorded once here; raw telemetry remains unchanged.
