问题入口为本目录的 `Spec.v`。当前解答是 `../attempts/001/`。

固定并复用 `paparazzi/models/guidance_pid_h_run_pos/align/model/{Source.v,Execution.v}`。研究原始 `guidance_pid_h_run_pos` 的 x、y 两轴：每一步均为原 CompCert Csem 调用，`in_flight=true`。每周期输入满足既有 `InputGood`：有效内存与帧、位置减法有符号安全、缓存有效、`approx_force_by_thrust=false`、固定编码增益均在 `[0,100]`，原有速度、加速度、积分、航向条件保持不变。每周期参考值、测量值、速度和加速度均符号量；环境只准备允许的输入字节并保持实际积分器。

参考运算保留相同编码输入误差及限幅、实际增益、前馈、算法顺序、PD 积分和全部三处饱和。动态算术右移替换为精确有理除法。令 `T=131072`、`S=65536`、`L=1429*S`，以整数分子精确实现：

```
PDnum = 2048*kp*Ep + kd*Ev
Totalnum = PDnum + kv*reference_speed + 512*ka*reference_accel
Jnext = clip(L*T, J + ki*PDnum)
Unext = clip(3216*T*S, S*clip(1429*T, Totalnum) + Jnext)
```

积分解释为 `J/T`，命令解释为 `U/(T*S)`；`RationalReference.v` 独立给出 `Q` 精确有理算法并证明这两个解释，以及 PD、总前馈解释。它保留导数的嵌套 `/4`、`/32768`，积分的是 PD 量。航向的浮点处理沿用原模型，未包含在本数值参考内。

初值关系 `SameStart` 允许任意原域合法的实际积分 `I0`，要求 `J0=T*I0`。设 `n` 为已完成的实际调用数，`a=2+3*kd/T`。请求证明：

1. 对任意有限 `n>=0`、任意合法逐周期输入、任一轴，参考积分数值减实际积分数值在 `[0,n*ki*a]`。
2. `n>=1` 时，从原实际全局命令字段和实际返回对象读取同一编码命令 `u_C`；参考命令 `u_ref` 满足
   `0 <= u_ref-u_C <= min(6432, 5+3*kd/T+n*ki*a/S)`。
3. `ReadyCycles` 的任意长度合法驱动必有原始实际调用轨迹；调用返回由已证原入口总性导出。
4. 每个合法原调用的全可达状态无错误及全后继终止性，复用原域已证定理。

6. 上述可执行整数参考与精确 `Q` 除法参考完全对应。

误差的有理分子形式是 `B=(5*T+3*kd)*S+n*ki*(2*T+3*kd)`，分母为 `T*S`。转换到弧度精确除以 `4096`，故分母为 `T*S*4096=35184372088832`。`n=0` 无命令观察要求。数值偏小表示向负方向的偏移；命令绝对值的变化取决于符号。
