# PID_df 增量与位置式 PID 的精确关系及舍入误差

[规范](Spec.v) 给出九个符号命题；[当前尝试](../attempts/001/report.md) 均已证明。

初始历史为 e₋₁=e₀=u₀=0。令 H=Ki·Ts/2，D=Kd/Ts。独立的位置式参考为
Uᴿₙ=P·eₙ+H·Σⱼ₌₁ⁿ(eⱼ+eⱼ₋₁)+D·(eₙ-eₙ₋₁)，即梯形积分与后向差分导数。
精确实数增量式系数为 A=P+H+D、B=−P+H−2D、C=D；先证明二者对所有符号 n 相等。

浮点定理要求存储的 a,b,c 和所有实际样本有限、绝对值不超过1，初始历史为原初始化的正零。对任意 n：
|uᶜₙ−Uᴿₙ| ≤ 2⁻²⁰·n(n+1)+n·Δ，
Δ=|real(a)−A|+|real(b)−B|+|real(c)−C|。
Δ明确保留原初始化系数预计算的舍入贡献，不用有效增益替代名义 P/Ki/Kd/Ts。

没有固定时域上限，也不以前提假定后续有限或局部误差。由 binary32 端点吸收证明实际累加器始终有限且 |uᶜₙ|≤2²⁴、|uᶜₙ|≤9n，再推导每步和累计误差。误差界随 n 增长；大状态处的小增量可能被舍入吸收，不宣称理想积分器与浮点输出永久接近。

执行目标直接使用原始 CompCert Csyntax/Csem update_pid_df，证明任意有限 n 的调用链存在，以及所有正常返回调用链的完整返回列表、实际字段/字节、写入前缀和 caller frame。原 init_pid_df 的精确浮点表达式已实例化系数误差项；不声称本单入口模型执行了 init_pid_df。

准备阶段 verification-request.json 记录原始高层目标（有限时域误差）；align/request.json 是自动导出 manifest 实际绑定的全机器执行请求。两者均保持冻结；最终任意 n 定理强化原有限时域目标，没有追溯改写请求。
