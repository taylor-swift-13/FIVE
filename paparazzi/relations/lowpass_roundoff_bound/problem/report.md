# 符号输入、任意拍数的低通更新舍入误差

规范为 [Spec.v](Spec.v)，当前证明为 [attempt 001](../attempts/001/report.md)。入口为原始 update_first_order_low_pass，Csyntax/Csem 模型保持不变。

对任意 binary32 存储系数 c、输入序列 x:nat→float32、初始输出 ŷ0，要求 c、全部 x_n、ŷ0 有限，1≤real(c)≤2，|real(x_n)|≤1，|real(ŷ0)|≤1。内存初态为合法、对齐、地址不回绕、已初始化、可写的12字节对象：系数c，last_in=x_0，last_out=ŷ0。

参考：yR_0=real(ŷ0)，yR_(n+1)=[real(x_(n+1))+real(x_n)+(real(c)−1)yR_n]/[1+real(c)]。使用同一存储系数的精确实数解释。实际运算严格按原C的binary32运算树，RNE，允许subnormal。

六目标：全n数值有限且幅度≤2；单步局部误差≤2^-20；全n误差≤2^-19(1−2^-n)≤2^-19；任意n的原Csem调用链存在；所有正常返回链的精确值、字段/系数字节/写区外frame及同一误差；数值域非空且所有admissible初态可由实际内存实现。

n为任意自然数，各拍输入可独立变化。不假设未来输出有限、局部误差界或未来调用存在。原模型已有的无错误和所有后继终止目标继续引用其已核验原证据，不由返回存在性代替。系数初始化、传感器量化及连续系统离散化误差不属于这里的更新运算舍入误差。
